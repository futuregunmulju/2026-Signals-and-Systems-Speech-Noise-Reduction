# 2026-Signals-and-Systems-Speech-Noise-Reduction
(2026 Fall) Traditional speech noise reduction challenge

# 음성 잡음 제거 (고전 신호처리, 딥러닝/머신러닝 미사용)

- 팀: **9조** 구조대
- 라운드: 2026 신호 및 시스템 1차 챌린지
- 제출 버전: 2차 제출 (tag `v6`)

## 실행 방법

```bash
pip install -r requirements.txt        # numpy, scipy, soundfile
python denoise.py --input_dir input --output_dir output
```

- `input_dir`의 모든 `.wav`를 같은 파일명으로 `output_dir`에 저장합니다. 길이, 샘플레이트, 채널 수, subtype은 입력과 동일하게 유지합니다.
- `best_params.json`(튜닝된 설정)이 `denoise.py`와 **같은 폴더**에 있어야 합니다. 있으면 자동으로 기본값을 덮어씁니다.
- 학습된 모델, 외부 데이터, 잡음 템플릿은 사용하지 않습니다. 사용 라이브러리: numpy, scipy, soundfile.

## 알고리즘 개요

STFT(기본 창 960 샘플 = 60 ms, hop 240 = 15 ms, 16 kHz) 영역에서 한 번의 이득(gain) 계산으로 처리하는 단일 파이프라인입니다. v5부터는 이 파이프라인을 분석 창이 다른 3개 설정(640/160, 960/240, 2048/512)으로 각각 돌리고 출력 파형을 평균합니다(앙상블). v6에서는 창마다 파라미터를 따로 재탐색했습니다. 잡음 유형별 모듈은 이득을 따로 곱하는 필터가 아니라, **잡음/말소리 추정치만 보정**합니다(필터 직렬 연결 없음).

1. **고역통과(HPF, 100 Hz, 영위상)**: 바람/럼블 제거.
2. **톤 억제(`_tonal_suppress`)**: 희소하고 시간적으로 연속인 스펙트럼 피크(정상 톤 잡음)를 노치.
3. **잡음 PSD 추정(`_noise_psd`)**: 비인과 최소통계 + 말소리 부재 가중 시간 평균(Martin, 2001 계열, `_noise_psd_base`, v2)에,
   양방향 SPP(음성 존재 확률) 기반 잡음 추적(Gerkmann & Hendriks, 2012 계열, `_spp_pass`, **v3 추가**)을 로그 영역에서 혼합.
4. **사이렌 궤적 추적(`_siren_track`)**: 스펙트럼 돌출도 → 하모닉 콤 현저도 → 스윕 속도를 제한한 Viterbi 경로. 클립에서 검출된 경우에만 사이렌 전력을 잡음 PSD에 더함.
5. **사전 SNR 추정**: Decision-directed (Ephraim & Malah, 1984) + 케프스트럼 평활 ML-SNR 혼합 (Breithaupt et al., 2007 계열).
6. **하모닉 콤(`_harmonic_mult`)**: 프레임별 케프스트럼 F0로 말소리 하모닉 사이 대역의 사전 SNR을 낮춤(유성음 신뢰도로 가중).
7. **MMSE-LSA 이득** (Ephraim & Malah, 1985) + 음성 휴지 구간 전용 이득 하한.
8. 저이득 영역 이득 평활(musical noise 억제), 소량의 원신호 leak. (v3까지 사용, **v4부터는 둘 다 끔**)
9. **앙상블(v5, v6)**: 창 크기가 다른 3개 설정의 출력을 동일 가중으로 평균. v5는 640/2048 멤버에 960 멤버의 파라미터를 hop 비율로 보정해 썼고, v6는 640/2048 멤버의 12개 파라미터를 각각 다시 탐색했습니다. 처리 시간은 v4의 약 3배.


## 버전별 변경점

### v2 (Validation 1.8395)
- 클립 전체를 보는 비인과 최소통계 잡음 PSD, Decision-directed + 케프스트럼 평활 사전 SNR
- 하모닉 콤, 사이렌 궤적 추적, 정상 톤 억제, 휴지 구간 전용 이득 하한

### v3 (Validation 1.8609, v2 대비 +0.0214)
- 잡음 PSD 추정에 **양방향 SPP 추적**을 추가하고 기존 추정과 로그 영역에서 혼합(혼합 비율 약 0.31)
- 입력 신호의 시간 변동 폭을 재서 혼합 비율을 조절하는 게이트 추가(카테고리 정보는 쓰지 않음)
- 파라미터 **전체 재튜닝**. 잡음 수준 배율(`noise_scale`) 등이 바뀜
- 이득의 출처를 분해하면 대부분은 재튜닝이고 SPP는 일부입니다(아래 표).

### v4 (Validation 1.9626, v3 대비 +0.1017 / 탐색에 쓰지 않은 Train 150개 홀드아웃 +0.0707)
- **분석 창을 640/160에서 960/240으로 확대**. 주파수 해상도가 높아져 말소리 하모닉과 잡음의 구분이 좋아졌고, 개선의 대부분이 여기서 나왔습니다(창 800~1280은 모두 비슷하게 좋은 넓은 구간).
- **이득 평활과 원신호 leak을 끔**. 재튜닝된 v3 파라미터 위에서는 오히려 방해가 됨을 단계별 제거 실험으로 확인했습니다.
- 새 창에서 프레임 단위 파라미터(`min_win`, `noise_sigma`)와 레벨 파라미터(`noise_scale`, 이득 하한 등) **12개를 다시 탐색**. 알고리즘 코드는 v3와 동일하고 파라미터(`best_params.json`)만 바뀝니다.
- 시험했지만 채택하지 않은 것: OM-LSA식 이득 수정(억제만 강해져 -0.015 이하), 양방향 decision-directed(-0.002 이하), 주파수별 이득 하한 기울기(효과 없음), 입력 SNR 적응형 파라미터(Validation +0.0006).

### v5 (Validation 1.9752, v4 대비 +0.0127 / 탐색에 쓰지 않은 Train 150개 홀드아웃 v4 1.9719 → v5 1.9867)
- **분석 창이 다른 3개 설정(640/160, 960/240, 2048/512)의 출력을 평균하는 앙상블** 추가. 창 해상도가 서로 많이 다를수록 오차가 서로 상쇄되어 이득이 컸습니다(비슷한 창 2개는 +0.003, 넓은 폭 3개는 +0.013~0.015).
- 알고리즘 본체(`denoise_channel`)는 v4와 동일하고, `denoise()` 래퍼와 `best_params.json`(`ensemble` 항목)만 바뀝니다. `ensemble`을 비우면 v4와 출력이 같습니다.
- 처리 시간은 파일당 약 3배(v4 약 0.7초 → 약 2초).
- 시험했지만 채택하지 않은 것: 사이렌이 검출된 클립은 앙상블 대신 단일 설정으로 처리(사이렌 오탐이 많아 오히려 이득이 줄어듦), 앙상블 멤버 6개(3개와 같은 점수, 비용만 2배), 대역별 SPP 게이트와 2패스 SPP(홀드아웃에서 모두 기준 이하).

### v6 (Validation 1.9794, v5 대비 +0.0042 / 탐색에 쓰지 않은 Train 150개 홀드아웃 v5 1.9867 → v6 1.9909)
- 앙상블 멤버 2개(640/160, 2048/512)의 12개 파라미터(`noise_scale`, `noise_sigma`, `min_bias`, `delta`, `min_win`, `alpha_dd`, `gain_floor_db`, `floor_pause_db`, `ceps_w`, `h_w`, `spp_w`, `tonal_db`)를 **멤버별로 다시 탐색**했습니다. v4에서 창을 바꿀 때 파라미터를 다시 맞춘 것이 가장 큰 이득이었던 것과 같은 이유입니다. 960/240 멤버는 v4와 동일합니다.
- 알고리즘 코드(`denoise.py`)는 v5와 동일하고 `best_params.json`의 `ensemble` 항목 안 멤버별 값만 바뀝니다.
- 채택 기준은 탐색에 쓰지 않은 Train 150개 홀드아웃과 Validation 둘 다 +0.003 이상 개선이었고, 홀드아웃 +0.0042(표준오차 0.0022), Validation +0.0041이었습니다. 탐색 중 체크포인트 선택에 Validation을 썼으므로 Validation 점수는 약간 낙관적일 수 있습니다.

## 파라미터 튜닝

- 파라미터는 Train 데이터 일부에서 **무작위/지역 탐색**으로 골랐고, Validation(164쌍)으로 확인했습니다.
- 모듈(케프스트럼, 휴지 바닥값, 하모닉, 사이렌) 채택 여부는 Validation 평균 개선량이 기준(+0.003~0.005)을 넘을 때만 결정했습니다. Validation을 선택에 사용했으므로 **Validation 점수는 약간 낙관적일 수 있습니다.**
- 학습 가능한 모델은 없고, 튜닝 대상은 수십 개의 스칼라 파라미터뿐입니다.
- v5: 앙상블 구성(창 조합 2~3개 부분집합 56가지, 6개 조합)은 탐색에 쓰지 않은 Train 150개 홀드아웃으로 골랐고, 최종 구성은 Validation으로 한 번 더 확인했습니다. 홀드아웃에서 여러 구성을 비교해 고른 값이라 홀드아웃 이득(+0.0148)은 약간 낙관적이고, Validation 이득(+0.0127)이 더 보수적입니다.
- v4: 창 크기(n_fft/hop) 격자와 구성요소 제거 실험으로 구조를 정한 뒤, 12개 파라미터를 Train 부분집합(약 86개)에서 119회 지역 탐색했습니다. Validation은 체크포인트 선택(12회)에만 썼으므로 낙관적일 수 있어, 탐색에 쓰지 않은 Train 파일 150개로 v3와 v4를 따로 비교했습니다(v3 1.9012 → v4 1.9719, +0.0707, 표준오차 0.0113).
- v3: SPP 파라미터 7개를 추가하고 잡음 수준 배율을 포함한 10개 파라미터를 다시 탐색했습니다. 탐색은 Train 부분집합으로, Validation은 체크포인트 선택에만 썼으므로 Validation 점수는 약간 낙관적일 수 있습니다.
